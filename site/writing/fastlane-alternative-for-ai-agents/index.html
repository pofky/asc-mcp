A fastlane alternative for AI agents

fastlane is a free, MIT-licensed Ruby command line tool, and its deliver and pilot actions can authenticate with the same kind of App Store Connect API key that asc-mcp uses. The difference for an agent is the interface: fastlane is reached by shelling out, while asc-mcp gives the agent 41 typed tools to call directly.

12 November 2026 · Povilas Konopackas · from the README and tool definitions of asc-mcp

What fastlane and asc-mcp share

Both talk to Apple through the App Store Connect REST API, authenticated with an API key (a .p8 file, a Key ID and an Issuer ID). Per fastlane's own docs, deliver and pilot can authenticate with such a key, while some actions, such as produce for creating an app, still need an Apple ID login. The release steps you would script with deliver and pilot have a matching tool in asc-mcp, with no Ruby toolchain. fastlane is a good tool, and this page is about a narrower question: what changes when the caller is an AI agent instead of a person or a CI job.

What changes when an agent is the caller

An agent reaches fastlane by running shell commands and reading text back. asc-mcp is an MCP server, so the agent sees 41 tools with typed inputs and calls them directly. There is no Fastfile to write first, and no output to parse.

  • Tools that send something outward need an explicit confirm: true: submit_for_review, release_version and upload_binary. Nothing is submitted by accident.
  • asc_setup_check tests the key, the Issuer ID, a live connection and the license, and prints the exact fix for each failure.
  • asc_guide returns the playbook for a flow, such as a first release, and marks the steps the API cannot do.

Setup happens in the chat

Add the server to your client. In Claude Code:

claude mcp add asc-mcp -- npx -y @pofky/asc-mcp

Create an API key at App Store Connect, Integrations, download the .p8, then tell the agent "connect asc-mcp, my Issuer ID is" followed by the UUID shown on that page. It calls asc_connect, which finds the downloaded key, files it in ~/.appstoreconnect/private_keys, tests it against Apple and unlocks every tool in the same conversation. The full steps are in setup on the home page.

The binary still builds on your Mac

An API cannot compile your app. build_and_archive runs xcodebuild archive and export locally, so Xcode must be installed. upload_binary then sends the .ipa to App Store Connect with altool and your API key, and asks for confirm: true. wait_for_build blocks until the build is valid, and attach_build puts it on the version.

What the API cannot do with a key

These are limits of the App Store Connect API used with a key, and asc-mcp does not work around them with an Apple ID login. You cannot create the app record with an API key. An app's first in-app purchases cannot be submitted over the API with the version. The app privacy questionnaire and EU trader status have no public endpoint. asc-mcp flags each of these in asc_guide before you reach it, and submit_for_review aborts rather than orphan a version when first in-app purchases block it. The full list, with the error each one returns, is on what the App Store Connect API cannot do.

When fastlane is the better fit

If a Fastfile already works for you, or releases run from CI with no agent involved, fastlane is free and does that job. asc-mcp is for the case where the agent in your editor should do the release steps itself, with typed calls and a checklist of what only a person can finish.

What asc-mcp costs

fastlane costs nothing. asc-mcp has a free tier. Asking your agent to run asc_start_trial unlocks all 41 tools for 7 days with no card and nothing to cancel. After that, Pro is $9 per month, VAT included, and in the US, Canada and India sales tax is added at checkout. Details are under pricing.

Questions

Is there a fastlane alternative for AI agents?

Yes. asc-mcp is an MCP server that gives an agent 41 typed tools for App Store Connect, using an App Store Connect API key, the same kind deliver and pilot can use. fastlane is a free MIT Ruby command line tool that an agent has to shell out to. Setup happens in chat with the asc_connect tool.

Does fastlane use the App Store Connect API?

Partly. Per fastlane's docs, deliver and pilot can authenticate with an App Store Connect API key, the same kind of key asc-mcp uses. Some actions, such as produce for creating an app, still sign in with an Apple ID. asc-mcp only ever uses the API key.

Can asc-mcp build and upload my app without fastlane?

Building still happens on your Mac. The build_and_archive tool runs xcodebuild through Xcode, and upload_binary sends the .ipa with altool using your API key. upload_binary requires confirm: true.

What does asc-mcp cost compared with fastlane?

fastlane is free. asc-mcp has a free tier and a 7-day trial with no card, then Pro is $9 per month, VAT included, with sales tax added at checkout in the US, Canada and India.
