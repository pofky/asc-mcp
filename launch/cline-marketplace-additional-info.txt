asc-mcp is an App Store Connect MCP server. It runs locally over stdio with Node 18 or newer, installed with npx -y @pofky/asc-mcp. The repo has an llms-install.md written for agents: add the server with no env vars, ask the user for their downloaded App Store Connect .p8 key and Issuer ID, then call asc_connect, which tests the key against Apple and loads all 45 tools in the same session. Six tools are free with no time limit. The rest have a 7-day trial with no card, then $9 a month. Every write to App Store Connect previews first and runs only with confirm: true. MIT licensed, listed in the official MCP Registry as io.github.pofky/asc-mcp.
